# WriteIt

WriteIt 是一个 Markdown 编辑器项目。

- `writeit-v2/`：当前开发主线。
- `editor-app/`：旧版实现，仅作为行为和测试参考。
- `experiments/`：架构实验与参考资料。

v2 设计与实施状态见 [`writeit-v2/docs/IMPLEMENTATION_SPEC.md`](writeit-v2/docs/IMPLEMENTATION_SPEC.md) 和 [`writeit-v2/docs/STATUS.md`](writeit-v2/docs/STATUS.md)。长程 Codex 执行入口见 [`writeit-v2/docs/GOAL.md`](writeit-v2/docs/GOAL.md)，前置产品/架构选择见 [`writeit-v2/docs/DECISIONS.md`](writeit-v2/docs/DECISIONS.md)。
