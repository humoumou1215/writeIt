# 全局搜索（全文搜索面板）

> 核心代码：`src/search/index.ts`（搜索引擎）+ `components/SearchPanel.vue`（侧栏面板）+ `editor/manager.ts` 的 `scrollToSearchMatch`（结果跳转定位）。
> 入口：图标列 🔍 或快捷键 `Ctrl+Shift+F`（可自定义）。
> 一句话：**全文搜索工作区所有可编辑文档——输入即搜，结果按文件分组，点击/Enter 直接打开文件并滚动到命中位置**。

## 1. 入口与面板

- **入口**：图标列 🔍（三套图标风格都有对应放大镜）；快捷键 `Ctrl+Shift+F` 打开（已打开时再按一次收起，与侧栏其它图标一致的切换语义）。
- 打开后面板自动聚焦输入框（`Ctrl+Shift+F` 重开时同样聚焦）。
- 面板在侧栏内容列第三个 tab（文件树 / Git / 搜索），复用同一侧栏宽度/收起/固定逻辑。

## 2. 搜索行为

- **范围**：当前可见文件树中的全部可编辑文档（`.md` / `.markdown` / `.txt`；`.git/` 排除）。
- **内容源**：已打开且已挂载的标签取**编辑器实时内容**（未保存的修改也能搜到，diff 态回退磁盘内容）；其余走 `fs.readFile`（按文件缓存，文件树结构变化自动失效）。
- **匹配**：默认忽略大小写；`Aa` 开关切换大小写敏感。逐行匹配，每文件最多 100 条、全量上限 4000 条。
- **并发**：最多 6 路并行读取，防大工作区卡顿；连续输入 220ms 防抖，新搜索自动丢弃过期结果。

## 3. 结果呈现

- 按文件路径字典序分组，文件头显示路径与命中数；每条命中显示行号 + 行内容（关键字高亮 `<mark>`）。
- 状态行实时显示「N 处匹配」/「搜索中…」/「无匹配结果」；空查询显示操作提示。

## 4. 跳转定位

- 点击命中行 / `Enter`：调用存量 `scrollToSearchMatch(path, lineText, needle)`——
  未打开则打开标签 → 切回所见即所得 → 在 ProseMirror doc 中按「行文本 → 关键词」两级定位并滚动到匹配处。
- 跳转完成后焦点自动归还搜索框（编辑器异步挂载会抢焦点，跳转落定后重试归还；用户手动点击即停止归还），
  方便连续翻看结果：`↑`/`↓` 在命中间移动选择，`Enter` 打开。

## 5. 关闭与快捷键

- `Esc`：先清空查询；查询已空时再按一次收起侧栏。
- 键盘导航依赖输入框焦点；输入框聚焦时全局快捷键不触发（与全局规则一致），关闭用 `Esc` 或点其它图标。

| 文件 | 职责 |
