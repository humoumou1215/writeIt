# 消金业务合作平台

一套业务管理系统：接收上游发送的意向贷款客户，经**路由**输出到不同下游机构，完成**助贷、增信**等业务，合作完成贷款发放。核心业务模块：路由、进件、助贷、增信。

## 目录约定

| 目录 | 含义 | 组织方式 |
| --- | --- | --- |
| `20260806/` 等 | 迭代窗口（批次），需求/设计文档按窗口归档 | 窗口 → 项目 |
| `流程图/` | 系统当前最新状态 · 流程图 | 按功能模块 |
| `接口文档/` | 本系统提供的接口服务 | 按功能模块 |
| `后端接口/` | 调用下游系统的接口 | 按下游系统 |
| `数据库/` | 表结构 + 数据维护 | 按 schema / 数据维护按日期 |
| `xxljob/` | 批任务管理 | 按执行器 |
| `配置/` | 运行配置 | 按类型（nginx / apollo）→ 应用 |
| `template/` | 模板域（待逐个确认） | 每模板一个目录 |

> 说明：流程图 / 接口文档 / 后端接口 / 数据库 / xxljob / 配置 保存的是**系统功能描述的当前最新状态**（活文档，跨窗口持续更新）；迭代窗口目录保存各迭代的需求与设计快照。

> 当前全部文件为**简单示例**，待逐文件确认模板与校验规则后完善。
