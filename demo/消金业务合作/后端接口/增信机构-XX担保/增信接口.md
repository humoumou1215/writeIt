# 增信申请接口（调用下游：增信机构-XX担保）

## 基本信息

| 项 | 值 | 备注 |
| --- | --- | :--- |
| 下游系统 | 增信机构-XX担保 | 被调用的外部系统全称 |
| 方法 | POST | |
| 路径 | /api/credit/apply | 外部系统提供的路径 |
| 版本号 | v1.0.0 | |
| 是否关键接口 | 是 | 涉及征信与资金交易；包含高风险字段（金额/业务状态/幂等） |
| 该接口涉及的业务范围 | 助贷增信 | |
| 并发限制要求 | TPS ≤ 3 | 与担保机构约定 |
| 超时时间 | 3s | |
| 重试机制 | 最多 3 次，指数退避 | 幂等键增信申请号去重 |
| 幂等规则 | [[#creditNo]] | 增信申请号作幂等键，重复请求返回原结果 |
| 防止重复调用外部接口的机制 | [[数据库/loan/loan_apply#status]] | 发送前更新记录状态（乐观锁），防止重复发起增信 |
| 交易状态判断 | [[#status]] | 明确成功=SUCCESS、明确失败=FAIL，其余=PROCESSING 视为处理中 |

## 接口详情

字段说明：

| 字段 | 类型 | 长度 | 是否高风险字段 | 高风险字段类型 | 数据来源 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| creditNo | string | 32 | 是 | 幂等 | [[数据库/loan/loan_apply#apply_no]] | 增信申请号，幂等键（关联放款申请号） |
| customerId | bigint | 20 | 否 |  | [[数据库/customer/customer_info#id]] | 客户ID |
| guaranteeAmount | bigint | 20 | 是 | 金额 | [[数据库/loan/loan_apply#amount]] | 担保金额（单位：分） |
| status | string | 16 | 是 | 业务状态 | [[数据库/loan/loan_apply#status]] | 增信状态：PROCESSING/SUCCESS/FAIL |

请求示例：

```json
{
  "creditNo": "CRD20260806001",
  "customerId": 100200300,
  "guaranteeAmount": 5000000
}
```

响应示例：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "creditNo": "CRD20260806001",
    "status": "PROCESSING"
  }
}
```
