# 进件推送接口（调用下游：助贷机构-XX助贷）

## 基本信息

| 项 | 值 | 备注 |
| --- | --- | :--- |
| 下游系统 | 助贷机构-XX助贷 | 被调用的外部系统全称 |
| 方法 | POST | |
| 路径 | /api/entry/push | 外部系统提供的路径 |
| 版本号 | v1.0.0 | |
| 是否关键接口 | 是 | 包含高风险字段（金额/期次/还款方式/业务状态/幂等） |
| 该接口涉及的业务范围 | 助贷进件 | |
| 并发限制要求 | TPS ≤ 5 | 2026-08-14 商务与助贷机构约定 |
| 超时时间 | 3s | |
| 重试机制 | 最多 3 次，指数退避 | 幂等键进件号去重 |
| 幂等规则 | [[#entryNo]] | 进件号作幂等键，重复推送返回原结果 |
| 防止重复调用外部接口的机制 | [[数据库/loan/loan_apply#status]] | 发送前更新记录状态（乐观锁），防止重复推送 |
| 交易状态判断 | [[#status]] | 明确成功=SUCCESS、明确失败=FAIL，其余=PROCESSING 视为处理中 |

## 接口详情

字段说明：

| 字段 | 类型 | 长度 | 是否高风险字段 | 高风险字段类型 | 数据来源 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| entryNo | string | 32 | 是 | 幂等 | [[数据库/loan/loan_apply#apply_no]] | 进件号，幂等键 |
| customerId | bigint | 20 | 否 |  | [[数据库/customer/customer_info#id]] | 客户ID |
| amount | bigint | 20 | 是 | 金额 | [[数据库/loan/loan_apply#amount]] | 贷款金额（单位：分） |
| term | int | 4 | 是 | 期次 | [[数据库/loan/loan_apply#term]] | 期数 |
| repaymentMethod | string | 16 | 是 | 还款方式 | [[数据库/loan/loan_apply#repayment_method]] | 还款方式（等额本息/等额本金/先息后本） |
| status | string | 16 | 是 | 业务状态 | [[数据库/loan/loan_apply#status]] | 进件状态：PROCESSING/SUCCESS/FAIL |

请求示例：

```json
{
  "entryNo": "ENT20260806001",
  "customerId": 100200300,
  "amount": 5000000,
  "term": 12,
  "repaymentMethod": "EQUAL_INSTALLMENT"
}
```

响应示例：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "entryNo": "ENT20260806001",
    "status": "PROCESSING"
  }
}
```
